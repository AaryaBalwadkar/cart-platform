# Cart Platform exam practice

A tiny shopping-cart DevOps demonstration for the provided case study. It validates a JSON inventory, serves a small status page from an Alpine container, deploys two Nginx replicas to the Docker Desktop Kubernetes cluster (accessed locally with `kubectl port-forward`), and creates a Terraform-generated endpoint file for Ansible to verify.

This is a classroom exercise, not a production shopping platform.

See [COMPLETE-GUIDE.md](COMPLETE-GUIDE.md) for the setup and exam runbook.
